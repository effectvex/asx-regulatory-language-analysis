# Removed analytical sections

This directory preserves the final histogram, thematic coding, and frame analysis that were removed from the main dashboard.

- `histogram-themes-frames-2015-2025.html` is a standalone interactive archive.
- `histogram-themes-frames-2015-2025.xlsx` contains all 1,045 histogram observations, yearly distribution statistics and outliers, theme and frame totals, yearly theme/frame tables, methodology notes, and summary charts.

The theme and frame results are exploratory deterministic dictionary outputs and have not received independent human validation. They are archived for transparency and are not part of the retained analysis.
