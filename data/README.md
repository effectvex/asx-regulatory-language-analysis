# Data files

- `processed/company-year-analysis.csv` is the principal company-year dataset used by the dashboard.
- `intermediate/balanced-regulatory-shard-*.json` contains extraction, term, theme, and frame results.
- `graph-data/*.csv` contains aggregations regenerated by `scripts/process-dashboard-data.ps1`.
- `manifests/` defines the retained ASX200 and ASX50 subsets and supplies sector metadata.

The annual-report PDFs and full extracted texts are not included.

Revenue fields and the experimental revenue scatter were removed because the original heuristic parser did not normalize reporting units reliably and sometimes selected percentages, segment figures, or note values instead of consolidated revenue.
