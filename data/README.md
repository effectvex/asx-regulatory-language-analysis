# Data files

- `processed/company-year-analysis.csv` is the principal company-year dataset used by the dashboard.
- `intermediate/balanced-regulatory-shard-*.json` contains reproducible extraction, term-count, theme, and frame results. Theme and frame fields support the separate experimental supplement and are not used in the main dashboard.
- `graph-data/*.csv` contains aggregations regenerated by `scripts/process-dashboard-data.ps1`.
- `manifests/` defines the retained ASX200 and ASX50 subsets and supplies sector metadata.

The annual-report PDFs and full extracted texts are not included.

Revenue is outside the published dataset because cross-company comparisons require consistent currencies, reporting units, and consolidated-value definitions.
